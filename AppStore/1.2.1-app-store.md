# Evening Reader 1.2.1 — App Store Connect copy

Version 1.2.1, build 17. The English listing is unchanged apart from the release notes.
Traditional Chinese (`zh-Hant`) is a new localization: add it in App Store Connect under
App Information → Localizable Information, and on the 1.2.1 version page.

The interface terms below match the app's string catalog (書庫, 劃重點, 光色, 附註,
暖度, 對比, 夜間, 儲存到 Evening Reader).

## English (U.S.)

### What's New in This Version

```
Evening Reader now reads in Traditional Chinese. When your iPhone or iPad is set to Traditional Chinese, so is every menu, panel and page of the app, the tour, and Save to Evening Reader in the share sheet. What you read stays in the language it was written in.
```

### Description, optional last line

The description can stay as it is. To mention the new language, end it with:

```
Evening Reader speaks English and Traditional Chinese.
```

### Description (4000)

```
護眼柔光，溫暖心靈。

Evening Reader 是一款只用一種顏色繪成的閱讀 App。所有畫面元素（頁面、文字、圖片、控制項）都取自同一道琥珀色階，讓螢幕看起來像一片發光的面板，而不是一支手機。你可以把暖度調向橘色或米色，在昏暗的房間裡調低光線、設定對比，或切換到夜間模式：近乎全黑的底色上，浮現琥珀色的字。喜歡的設定可以存成光色，輕點一下即可切換。

儲存任何內容
從 Safari 或任何 App 把網頁分享到 Evening Reader、貼上連結，或打開一本書。文章會精簡成文字與圖片，並以閱讀器的字體排版，字型、大小、行距與欄寬都由你決定。PDF 保留原本的頁面。EPUB 書籍會連同封面、章節與目錄一起匯入。

離線閱讀
你儲存的一切都會下載並保存：文字、圖片、整本書。在火車上存下的內容，到了飛機上依然都在。

你的書庫，就是資料夾
書庫由一般的資料夾組成，每篇文章一個，裡面有文字、圖片和一份 Markdown 副本，透過你自己的 iCloud 雲碟同步，可以在「檔案」App 或 Mac 上閱讀。兩部裝置不會互相覆寫，你儲存的內容也不會被鎖在 App 裡。

劃重點與保留
選取一段文字即可劃重點、加上附註、查詢字詞、搜尋，或透過 Apple Intelligence 在裝置上詢問相關問題。整個書庫的重點都集中在同一頁，點一下就能回到原文段落。

找到你讀到的地方
一條細線顯示你讀了多少；拖動捲軸即可翻頁，或捲動整本書。首頁會打開你正在讀的內容與剛送達的文章。閱讀進度會在你的裝置之間同步。

琥珀色的網路
內建瀏覽器會把任何網站畫在同一片面板上：你的書庫、你的書店、報紙、影片，並為你特地常去的每個地方準備一個圖塊。

為一天結束時的放鬆時光而打造。
```
